Project 1

Academic Nexus

Full-Stack Web Application

A simple student portal where users register with a name, age, and password, log in, and enter marks for three subjects. A personalized dashboard shows a chart of total marks. Users can view academic records with pass/fail results per record, update marks by selecting a subject, log out, and delete their account.

Technologies

  • Python
  • Flask
  • HTML
  • CSS
  • JavaScript
  • Supabase
  • Replit
  • GitHub

My contribution

I built this mainly to learn how authentication and session-based web applications work: sessions, session cookies, JWT concepts, and Row Level Security (RLS) policies in a database. The interface was designed with Google Stitch, and Claude AI assisted with development and code generation. My focus was understanding the architecture, authentication, session management, and database permissions. I did not write all of the code independently.

Visual representation of the Container With Most Water problem.

Project 2

Water Area Calculator — Algorithm Visualization

Algorithm Design and Interactive Visualization

A visual solution to the LeetCode problem "Container With Most Water." The user enters a sequence of height values in a React frontend, which sends them to a Python Flask backend. The backend calculates the maximum area and returns it, and the frontend displays the result as a visual representation of the problem. The goal is to connect the input, the answer, and the picture to make the algorithm easier to understand.

Technologies

  • React
  • JavaScript
  • Python
  • Flask
  • GitHub
  • Replit (development and testing)

My contribution

I implemented the problem-solving algorithm myself. Claude AI assisted in creating the React frontend and the Python Flask integration. I did not independently develop every component of the application.

Project 3

Balaaj Affiliate Electronics

Static Website Development

A static product-display website with an e-commerce-style layout. It shows affiliate products with names, prices, sale details, and product links. It has no checkout, payments, or order management.
